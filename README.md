# gestion-academique
Objectif : développer une application permettant de gérer les informations académiques des étudiants.  Technologies : - Langage C - Structures de données - Listes chaînées et arbres binaires - Manipulation de fichiers Fonctionnalités : - Gestion des étudiants - Calcul des moyennes - Classement - Recherche par identifiant - Sauvegarde des données
